# 中国地图闯关 Pro

这是基于 GitHub 仓库 `lishuangcheng1/-` 的电脑端优化版小游戏。

## 怎么打开

直接双击 `index.html`，或在浏览器里打开：

```text
/Users/lishuangcheng/Documents/回忆视频/github-geography-game-optimized/index.html
```

## 主要优化

- 更适合电脑大屏的左右布局：左侧大地图，右侧答题和知识卡。
- 增加得分、连对、进度、正确率。
- 增加键盘快捷键：Enter 提交、N 下一题、H 提示、+/- 缩放。
- 增加智能提示、地区筛选、错题本、自由学习模式。
- 视觉风格更清爽，地图和面板层级更清楚。

## 注意

地图边界数据会从原仓库的 GitHub Pages 地址读取：

```text
https://lishuangcheng1.github.io/-/china-provinces.geojson
```

如果网络无法访问 GitHub Pages，地图可能无法显示。
